# BRD-lite: Nosiah Studios Portfolio V1

**Status:** Approved from conversation  
**Sponsor / Product owner:** Portfolio owner  
**Last updated:** 2026-08-03

## Business objective

**BRD-OBJ-001:** Replace the generic Next.js starter with a distinctive public portfolio that presents Nosiah Studios as the umbrella brand, showcases selected work and technical capability, and gives prospective collaborators a clear path to make contact.

## AS-IS / TO-BE

- **AS-IS:** The public route is the untouched Create Next App screen with no brand, work, or contact information.
- **TO-BE:** Visitors can understand the studio positioning, browse an honest project archive, inspect individual case-study shells, see the current build stack, and reach the studio from any primary page.

## SMART metric

By the V1 handoff, 100% of the defined public routes must build statically, pass the automated content contract tests, remain usable at 320px and desktop widths, and expose a visible contact action without relying on JavaScript.

## Scope fence

In scope: brand system, responsive site shell, homepage, work index, dynamic work detail pages, editable local content, SEO metadata, accessibility baseline, and deployment-ready build.

Out of scope: CMS, authentication, database, blog, analytics vendor, contact form backend, invented client outcomes, and final case-study photography.
